Educational Info

B-Tree Property (Order m)

  • Max children = m
  • Max keys = m - 1
  • Min children (internal) = ⌈m/2⌉
  • All leaves are at the same depth.
  • Keys are sorted in each node.

B+ Tree Specifics

  • Internal nodes only store routing keys.
  • All data values are in leaf nodes.
  • Leaf nodes are linked in a list for fast range queries.

Time Complexity

Operation B-Tree B+ Tree
Search O(log n) O(log n)
Insert O(log n) O(log n)
Delete O(log n) O(log n)
Range Query Slower Faster (O(log n + k))

Key Differences

Storage: B-Tree stores data at both internal and leaf nodes. B+ Tree stores data only at leaf nodes.

Search: B-Tree search can terminate early if key is found in internal node. B+ Tree search always goes to leaf.

Traversal: B+ Tree has linked leaves making sequential access very fast.

Usage: B+ Trees are highly preferred in Database systems and File systems.
